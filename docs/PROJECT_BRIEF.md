# Project brief

Kairix Quick A/V Sync is a small Windows utility for practical audio/video synchronization checks:

```text
open EXE → select capture card → configure → ARMED → clap → result
                                                     ↓
                                      clap again → newest result replaces previous
                                                     ↓
                                                  continue
```

The latest automatic clap remains displayed while automatic detection continues behind it. No Resume Live action is required between automatic events. Manual Clap opens explicit inspection with independently editable audio and visual points.

Kairix is not a recording library, database, account service, or cloud product. Media stays in bounded RAM and the application has no telemetry. It is intended eventually to operate unattended for hours or days, but that duration is a design goal—not a validated claim.
